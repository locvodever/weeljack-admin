# Assets

One line per art file the template ships: images, illustrations, inline icons copied from an icon set, and
screenshots. Code and styles written for this repo are covered by [LICENSE](LICENSE). npm dependencies, fonts
included, are covered by `check:licences`.

Every image is CC0 or made for the template: drawn as SVG, or a screenshot of the template itself. Nothing comes from
Sakai, Sparked or PrimeTek's demo set (see [ADR 0001](docs/adr/0001-rebuild-never-copy.md)).
